# Rodent Rumble

I made this game in high school.

It's hella fun.

### Play the game

####  [Hosted](https://rodentrumble.thinkmap.ai)

or

#### In terminal (with saving)
```bash
# Clone the repo
git clone https://github.com/wiesenthal/rodentrumble.git
# Navigate to the repo
cd rodentrumble
# Run the game in terminal
python3 script.py
```
